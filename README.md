# gigaspray

Credential tracking and spray automation for OSCP/CTF engagements.

gigaspray wraps [NetExec (nxc)](https://github.com/Pennyw0rth/NetExec) to give you a persistent workspace that accumulates credentials and hosts as you enumerate, then sprays them across protocols on demand. Valid hits are automatically recorded.

---

## Requirements

- `bash` 4.0+
- [`nxc` (NetExec)](https://github.com/Pennyw0rth/NetExec)

---

## Installation

```bash
git clone https://github.com/yourusername/gigaspray
cd gigaspray
chmod +x gigaspray.sh
```

Optionally symlink it onto your PATH:

```bash
ln -s "$(pwd)/gigaspray.sh" /usr/local/bin/gigaspray
```

Set your workspace path in your shell config so you don't have to pass `-d` every run:

```bash
export GIGASPRAY_DIR="/path/to/your/engagement/gigaspray"
```

---

## Quick Start

```bash
# 1. Create a workspace
gigaspray init

# 2. Add hosts as you find them
gigaspray --add -h 10.10.10.5        # IP — nxc auto-resolves hostname/domain
gigaspray --add -h corp.local        # domain name
gigaspray --add -h dc01.corp.local   # FQDN

# 3. Add credentials as you find them
gigaspray --add -u john -p 'P@$$w0rd'
gigaspray --add -u john -H aad3b435b51404eeaad3b435b51404ee

# 4. Spray
gigaspray --spray-smb
gigaspray --spray-all
```

## Workspace

Running `gigaspray init` creates a workspace directory with the following layout:

```
gigaspray/
├── all_user.txt          # all unique usernames
├── all_pass.txt          # all unique passwords
├── all_hashes.txt        # all unique NTLM hashes
├── user_paired.txt       # usernames paired 1:1 with pass_paired.txt
├── pass_paired.txt       # passwords paired 1:1 with user_paired.txt
├── hash_user_paired.txt  # usernames paired 1:1 with hashes_paired.txt
├── hashes_paired.txt     # hashes paired 1:1 with hash_user_paired.txt
├── creds.txt             # human-readable log: user:pass/hash:description
├── valid_creds.txt       # auto-populated on spray hits: user:cred:protocol:host
├── hosts.txt             # /etc/hosts format (generated by nxc)
├── hosts_ip.txt          # IPs only
├── hosts_dn.txt          # domain names / short hostnames
├── hosts_fqdn.txt        # FQDNs
└── logs/
    └── gigaspray.log     # timestamped log of all operations
```

## Usage

```
gigaspray [global options] <command> [command options]
```

### Global options

| Flag | Description |
|------|-------------|
| `-d <path>` | Workspace path (overrides `$GIGASPRAY_DIR`) |
| `-q` | Quiet — show only `[+]` hits on terminal |
| `-o <name>` | Save full spray output to `logs/<name>` |
| `--spray-hosts <value>` | Override the default spray target (`hosts_ip.txt`) |

`--spray-hosts` accepts a single IP, domain, FQDN, CIDR range, or a file of targets (one per line). When omitted, `hosts_ip.txt` from the workspace is used.

---

### Commands

#### `init`

Create a new gigaspray workspace.

```bash
gigaspray init
gigaspray -d /opt/labs/htb init
```

---

#### `--add` — Add credentials or hosts

```bash
# Single credential (flags)
gigaspray --add -u john -p 'P@$$w0rd' --desc 'found in web.config'
gigaspray --add -u john -H aad3b435b51404eeaad3b435b51404ee

# Inline user:pass shorthand
gigaspray --add 'john:P@$$w0rd'

# Bulk import
gigaspray --add -U users.txt                   # usernames only
gigaspray --add -P passwords.txt               # passwords only
gigaspray --add -U users.txt -P passwords.txt  # paired line-by-line
gigaspray --add -L creds.txt                   # user:pass file

# Add a host
gigaspray --add -h 10.10.10.5       # IP — nxc probes for hostname and domain
gigaspray --add -h dc01.corp.local  # FQDN
gigaspray --add -h corp.local       # domain name
```

When an IP is added, gigaspray runs `nxc smb` against it to resolve the hostname and domain, then populates `hosts_ip.txt`, `hosts_dn.txt`, `hosts_fqdn.txt`, and regenerates `hosts.txt`.

---

#### `--spray-<proto>` / `--spray-all` — Standalone sprays

Sprays all credentials in the workspace against all hosts.

```bash
gigaspray --spray-smb
gigaspray --spray-rdp
gigaspray --spray-winrm
gigaspray --spray-ssh
gigaspray --spray-ldap
gigaspray --spray-ftp
gigaspray --spray-mssql
gigaspray --spray-all        # all of the above in sequence
```

Supported protocols and their default ports:

| Flag | Protocol | Port |
|------|----------|------|
| `--spray-smb` | SMB | 445 |
| `--spray-rdp` | RDP | 3389 |
| `--spray-winrm` | WinRM | 5985/5986 |
| `--spray-ssh` | SSH | 22 |
| `--spray-ldap` | LDAP | 389 |
| `--spray-ftp` | FTP | 21 |
| `--spray-mssql` | MSSQL | 1433 |

All sprays run with `--continue-on-success`.

---

#### Spray immediately after `--add`

Spray flags can be appended to `--add` to spray with the newly-added credential the moment it's added. The fixed side is the new value; the other side falls back to the workspace files.

```bash
# New user → spray with all_pass.txt and all_hashes.txt
gigaspray --add -u john --spray-smb

# New password → spray with all_user.txt
gigaspray --add -p 'P@$$w0rd' --spray-all

# New user+pass pair → spray that specific pair
gigaspray --add -u john -p 'P@$$w0rd' --spray-smb --spray-winrm

# New hash → spray with all_user.txt
gigaspray --add -H aad3b435b51404eeaad3b435b51404ee --spray-smb
```

---

### Output control

```bash
# Hits only on terminal (full output still written to log files)
gigaspray --spray-smb -q

# Save full output to logs/smb_round1
gigaspray --spray-smb -o smb_round1

# Both
gigaspray --spray-smb -q -o smb_round1
```

---

### Overriding spray targets

```bash
gigaspray --spray-smb --spray-hosts 10.10.10.5
gigaspray --spray-smb --spray-hosts 192.168.1.0/24
gigaspray --spray-smb --spray-hosts dc01.corp.local
gigaspray --spray-smb --spray-hosts targets.txt
gigaspray --add -u john -p pass --spray-smb --spray-hosts 10.10.10.5
```

## Valid credential tracking

Whenever a spray returns a `[+]` hit, gigaspray automatically parses the nxc output and appends the result to `valid_creds.txt` in the format:

```
user:credential:protocol:host
```

Examples:

```
john:P@$$w0rd:smb:10.10.10.5
svc_backup:aad3b435b51404eeaad3b435b51404ee:smb:10.10.10.5
administrator:P@$$w0rd:winrm:10.10.10.5
```

Entries are deduplicated — the same hit won't be written twice. All hits are also recorded in `logs/gigaspray.log` with a timestamp.

## Workflow example

```bash
export GIGASPRAY_DIR="/opt/htb/active/gigaspray"
gigaspray init

# Recon phase — populate workspace as you go
gigaspray --add -h 10.10.10.100
gigaspray --add -u administrator
gigaspray --add -u svc_backup
gigaspray --add -p 'Welcome1'
gigaspray --add -p 'Summer2024!'

# Found a cred in a config file — add and spray immediately
gigaspray --add -u john -p 'P@$$w0rd' --spray-all

# Later — bulk import from a wordlist and spray
gigaspray --add -U /usr/share/seclists/Usernames/top-usernames-shortlist.txt
gigaspray --spray-smb -q -o smb_bulk

# Check what worked
cat "$GIGASPRAY_DIR/valid_creds.txt"
```
